Help & Settings

Frequently Asked Questions (FAQ's)

Common panel setting questions, answered in English & Telugu.

English: Hold the green UP button for 3 seconds until the display shows 1, 2, 3, 4… Press UP to add minutes, or the red DOWN button to reduce minutes. Release at your desired minute — it auto-saves, no need to press SET. Note: the OFF Timer only works if the motor wires are connected.

తెలుగు: ఆకుపచ్చ UP బటన్‌ను 3 సెకన్లు నొక్కి పట్టుకోండి, డిస్‌ప్లేలో 1, 2, 3, 4… కనిపిస్తుంది. నిమిషాలు పెంచడానికి UP నొక్కండి, తగ్గించడానికి ఎరుపు DOWN నొక్కండి. మీకు కావలసిన నిమిషం వద్ద వదిలేయండి — ఇది ఆటోమేటిక్‌గా సేవ్ అవుతుంది, SET నొక్కాల్సిన అవసరం లేదు. గమనిక: మోటారు వైర్లు కనెక్ట్ అయి ఉంటేనే ఆఫ్ టైమర్ పనిచేస్తుంది.

English: Press and hold SET for 3 seconds to enter settings, select oL, then use UP/DOWN to adjust the amperage (A) to match your motor. Press SET again to save and confirm.

తెలుగు: సెట్టింగ్స్‌లోకి వెళ్లడానికి SET బటన్‌ను 3 సెకన్లు నొక్కి పట్టుకోండి, oL ఎంచుకోండి, తర్వాత మీ మోటారుకు సరిపోయేలా UP/DOWN తో ఆంపియర్ (A) విలువను సర్దండి. సేవ్ చేసి నిర్ధారించడానికి మళ్లీ SET నొక్కండి.

English: Press SET, select drY, then use UP/DOWN to set the amperage (A) at which the panel should detect dry-run/no-load. Press SET again to save and confirm. As a guide: set oL to your motor's running amps + 2A, and drY to running amps − 2A.

తెలుగు: SET నొక్కండి, drY ఎంచుకోండి, తర్వాత పంప్ డ్రై-రన్/నో-లోడ్‌ను గుర్తించాల్సిన ఆంపియర్ (A) విలువను UP/DOWN తో సెట్ చేయండి. సేవ్ చేసి నిర్ధారించడానికి మళ్లీ SET నొక్కండి. సూచన: oL విలువను మీ మోటారు రన్నింగ్ ఆంప్స్ + 2A గాను, drY విలువను రన్నింగ్ ఆంప్స్ − 2A గాను సెట్ చేయండి.

English: These are typical starting points — always verify against your motor's actual rated and running amps before finalizing.

తెలుగు: ఇవి సాధారణ ప్రారంభ విలువలు — తుది నిర్ణయం ముందు మీ మోటారు యొక్క వాస్తవ రేటెడ్ మరియు రన్నింగ్ ఆంప్స్‌ను తప్పకుండా సరిచూసుకోండి.

English: "oL" means the motor current has exceeded the set overload limit — check the pump/motor for jamming or overheating before resuming. "drY" means the panel detected no-load/dry-run conditions, usually because the water source has run out — check the source before restarting.

తెలుగు: "oL" అంటే మోటారు కరెంట్ సెట్ చేసిన ఓవర్‌లోడ్ పరిమితిని మించిపోయింది — మళ్లీ ఆన్ చేసే ముందు పంప్/మోటారులో జామింగ్ లేదా వేడెక్కడం లేదని చూసుకోండి. "drY" అంటే ప్యానెల్ నో-లోడ్/డ్రై-రన్ పరిస్థితిని గుర్తించింది, సాధారణంగా నీటి మూలం అయిపోవడం వలన — మళ్లీ ఆన్ చేసే ముందు నీటి మూలాన్ని తనిఖీ చేయండి.

English: Connect the supply R-Y-B and motor A-B-C wires correctly — the display reads OFF when the wiring and incoming phases are healthy (415V). If the panel shows power OFF due to a phase fault, swap any two INPUT phases and check again.

తెలుగు: సరఫరా R-Y-B మరియు మోటారు A-B-C వైర్లను సరిగ్గా కనెక్ట్ చేయండి — వైరింగ్ మరియు వచ్చే ఫేజులు సరిగ్గా ఉంటే డిస్‌ప్లే OFF చూపిస్తుంది (415V). ఫేజ్ సమస్య వలన ప్యానెల్ పవర్ ఆఫ్ చూపిస్తే, ఏవైనా రెండు ఇన్‌పుట్ ఫేజులను మార్చి మళ్లీ తనిఖీ చేయండి.

English: Press SET — the display shows OL. Use the START/STOP buttons to adjust the amperage to match your motor's rated current, then press SET again to confirm.

తెలుగు: SET నొక్కండి — డిస్‌ప్లేలో OL కనిపిస్తుంది. మీ మోటారు రేటెడ్ కరెంట్‌కు సరిపోయేలా START/STOP బటన్లతో ఆంపియర్ విలువను సర్దండి, తర్వాత నిర్ధారించడానికి మళ్లీ SET నొక్కండి.

English: Press SET again — the display shows drY. Use START/STOP to adjust the amperage at which the panel should detect dry-run/no-load, then press SET again to confirm.

తెలుగు: మళ్లీ SET నొక్కండి — డిస్‌ప్లేలో drY కనిపిస్తుంది. ప్యానెల్ డ్రై-రన్/నో-లోడ్‌ను గుర్తించాల్సిన ఆంపియర్ విలువను START/STOP తో సర్దండి, తర్వాత నిర్ధారించడానికి మళ్లీ SET నొక్కండి.

English: Press SET again to show "t". Use START/STOP to set the number of minutes for the timer. Press SET once more to exit settings.

తెలుగు: మళ్లీ SET నొక్కితే "t" కనిపిస్తుంది. టైమర్ కోసం నిమిషాలను START/STOP తో సెట్ చేయండి. సెట్టింగ్స్ నుండి బయటకు రావడానికి SET మళ్లీ నొక్కండి.
